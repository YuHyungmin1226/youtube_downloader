# YouTube 최고화질 다운로더 (YouTube Best Quality Downloader)

YouTube 영상 링크(URL)를 붙여넣으면 그 영상이 제공하는 **최고화질(4K UHD, 2K QHD, 1080p60 등)**을 자동으로 찾아 영상과 음성을 합쳐 받아 주는 단일 실행 파일 데스크톱 프로그램입니다.
영상 1개뿐 아니라 **재생목록·채널 전체**를 순서대로 받을 수 있고, **MP3 음원만 추출**할 수도 있습니다.

---

## ✨ 주요 기능

- **🎬 최고화질 자동 다운로드**
  - 영상이 지원하는 가장 좋은 영상 스트림과 음성 스트림을 찾아 MP4로 합칩니다.
  - 미리보기 카드에 `최고 4K · 2160p60`처럼 받을 수 있는 최고 화질이 표시됩니다. (세로 쇼츠는 짧은 변 기준)
  - **호환성 우선 모드**(설정): PowerPoint·한컴·오래된 플레이어에서 재생이 안 될 때 H.264/AAC(최대 1080p)로 받습니다.
- **🛡️ YouTube 차단 대응**
  - 초경량 QuickJS 엔진(`bin/qjs.exe`)과 서명 해제 스크립트(yt-dlp-ejs)를 내장해 Node.js 설치 없이 YouTube JS 챌린지를 풉니다.
  - YouTube 접속 방식은 yt-dlp가 관리하는 최신 기본 조합을 그대로 사용하고, 403 차단이 확인된 경우에만 다른 접속 방식으로 한 번 더 시도합니다.
- **📺 재생목록 · 채널 전체 다운로드**
  - `@채널명`, `/channel/…`, `/c/…`, `/user/…` 주소는 채널의 **동영상** 탭으로 자동 정리합니다. (쇼츠·라이브 탭 주소는 그대로 유지)
  - 채널은 `저장 폴더/채널 이름/`, 재생목록은 `저장 폴더/재생목록 이름/` 폴더에 저장합니다.
  - 이미 받은 영상은 건너뛰고, 삭제·비공개 영상이나 진행 중인 라이브 방송도 건너뛰며 계속 진행합니다. 끝나면 `N개 저장 · M개 실패`처럼 결과를 정확히 알려 줍니다.
  - 진행 중 `[3/24] 영상 제목`처럼 현재 항목을 표시하고, 언제든 **중지**할 수 있습니다. (중지하면 받던 임시 파일은 자동 정리)
- **🎵 MP3 음원 추출**: 가장 좋은 음원을 받아 MP3(320kbps)로 변환합니다.
- **🧾 알기 쉬운 상태 · 오류 안내**
  - 진행률은 영상 받기 → 음성 받기 → 합치기 순서로 끊김 없이 올라가고, 속도 · 남은 시간 · 크기가 함께 표시됩니다.
  - "비공개 영상", "연령 제한", "인터넷 연결 확인" 등 오류를 한국어로 안내하며, 자세한 원인은 **상세 로그**에서 볼 수 있습니다.
- **🖼️ 깔끔한 다크 UI**
  - 링크를 붙여넣거나(메신저에서 복사한 문장 속 링크도 인식) 창에 끌어다 놓으면 썸네일·제목·채널·재생 시간이 바로 표시됩니다.
  - 다운로드가 끝나면 **재생** / **폴더 열기**(받은 파일이 선택된 상태) 버튼이 나타납니다.
  - Windows 라이트/다크 모드와 관계없이 같은 모습으로 보이고, 오른쪽 클릭 메뉴 등 기본 문구도 한국어로 표시됩니다.
- **📦 설치 없이 실행**: FFmpeg와 JS 엔진이 exe 안에 들어 있습니다. (소스 실행 시 없으면 첫 다운로드 때 사용자 폴더에 자동 준비)

## 🚀 빠른 시작

### 방법 1. 실행 파일 사용 (가장 간편함)
1. `python build.py`로 만든 `release/YouTube_Downloader.exe`를 실행하거나, 함께 만들어지는 ZIP(`YouTube_Downloader_vYYYY.MM.DD_Windows.zip`)을 원하는 PC에 복사해 압축을 풉니다.
2. `YouTube_Downloader.exe`를 실행합니다. Python 설치는 필요 없습니다.

> `release/` 폴더는 빌드할 때 로컬에서 만들어지며 Git 저장소에는 포함되지 않습니다.

### 방법 2. 간편 실행 스크립트 (run.bat)
저장소를 받은 뒤 `run.bat`을 더블 클릭하면 필요한 패키지를 확인·설치한 뒤 프로그램을 실행합니다. (Python 3.10 이상 필요)

### 방법 3. 소스 코드에서 직접 실행
```bash
pip install -r requirements.txt
python youtube_downloader.py
```

### 방법 4. CLI (터미널) 모드
```bash
# 최고화질 영상 다운로드
python youtube_downloader.py --url "https://www.youtube.com/watch?v=..."

# MP3 음원만 추출
python youtube_downloader.py --url "https://www.youtube.com/watch?v=..." --audio-only
```

### YouTube가 바뀌어 다운로드가 안 될 때
YouTube는 자주 구조를 바꿉니다. 소스로 실행 중이라면 아래 명령으로 yt-dlp를 최신으로 올린 뒤 다시 시도하세요. (exe는 새로 빌드하면 최신 yt-dlp가 들어갑니다)
```bash
python -m pip install -U "yt-dlp[default]"
```

## 🔨 실행 파일(.exe) 빌드

```bash
pip install -r requirements-build.txt
python build.py
```

- QuickJS(`bin/qjs.exe`), yt-dlp-ejs, FFmpeg(imageio-ffmpeg), 앱 아이콘이 하나의 `.exe` 안에 포함됩니다.
- 사용하지 않는 대용량 Qt 모듈(Qt3D, QtWebEngine 등)은 빼서 크기를 줄입니다.
- 결과물은 `release/`에만 남고, 빌드 중 생기는 `build/`, `dist/`, `.spec` 파일은 성공·실패와 관계없이 자동 정리됩니다. 이전 이름의 exe나 예전 날짜 ZIP도 정리되어 `release/`에는 최신 결과물만 남습니다.
- **산출물**
  - `release/YouTube_Downloader.exe` (단일 실행 파일)
  - `release/YouTube_Downloader_vYYYY.MM.DD_Windows.zip` (exe + README 배포용 압축)

## ⚙️ 설정

오른쪽 위 **설정** 버튼에서 바꿀 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| 저장 위치 | 영상·음원이 저장될 폴더 (기본값: 사용자 `다운로드` 폴더). 메인 화면의 **변경**/**열기** 버튼으로도 바꿀 수 있습니다. |
| 완료 후 | 다운로드가 끝나면 저장 폴더 자동으로 열기 |
| 화질 방식 | **호환성 우선 (H.264 · 최대 1080p)** — 끄면 4K·HDR 등 최고화질(AV1/VP9)로 받습니다. |
| 재시도 횟수 | 네트워크가 불안정할 때 자동으로 다시 시도하는 횟수 (0~10회) |
| FFmpeg / JS 엔진 | 사용 가능 여부 표시 (없으면 첫 다운로드 때 자동 준비) |

- 설정은 사용자 홈 폴더의 `youtube_downloader_config.json`에 저장됩니다.
- 파일 이름은 `영상 제목 [영상ID].mp4` 형식입니다. 제목이 같은 다른 영상이 "이미 받은 파일"로 잘못 건너뛰어지지 않도록 영상 ID를 붙입니다.

## ⚠️ 알아 두기

- **라이브 방송**(진행 중·예정)은 방송이 끝난 뒤에 받을 수 있습니다.
- **비공개 · 멤버십 전용 · 연령 제한** 영상은 로그인이 필요해 받을 수 없습니다.
- 검색 결과·구독 피드 페이지 주소는 받을 수 없습니다. 영상·재생목록·채널 링크를 넣어 주세요.
- 저작권이 있는 콘텐츠는 권리자가 허용한 범위에서만 사용하세요.

## 🏗️ 프로젝트 구조

```
youtube_downloader/
├── youtube_downloader.py   # 메인 애플리케이션 (GUI, 다운로드 엔진 단일 파일)
├── build.py                # PyInstaller 빌드 및 릴리스 ZIP 생성 스크립트
├── run.bat                 # 원클릭 의존성 확인 및 실행기
├── requirements.txt        # 실행에 필요한 패키지
├── requirements-build.txt  # exe 빌드에 필요한 패키지 (requirements.txt 포함)
├── icon.png / icon.ico     # 앱 아이콘
├── bin/
│   └── qjs.exe             # YouTube 서명 해제용 초경량 QuickJS 런타임 (2.1MB)
└── release/                # 빌드 결과물 (로컬 생성, Git 제외)
```

## 📝 시스템 요구사항

- **운영체제**: Windows 10/11 (64-bit). 소스 실행은 macOS 11+, Linux도 지원
- **Python**: 3.10 이상 (소스 실행 및 빌드 시에만 필요)
- **네트워크**: 인터넷 연결 필수
